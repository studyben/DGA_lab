## Project instructions, architecture, and ownership

- The frontend calls only the laboratory module's public HTTP surface; it does not depend on table or component implementation details.
- The browser fixture creates sample identity only. Detection, finalization, report queueing, worker generation, storage, download, withdrawal and regeneration all cross the production public seams.
- The browser object store and database are isolated and ephemeral. The fixture guard still rejects any database other than `db/dga_browser/dga_browser`.
- Polling is restricted to queued/generating states, capped at 20 attempts, and its timer/request are cancelled on a new search or unmount.
- Failed retry is shown only to sessions with `laboratory.finalize`.
