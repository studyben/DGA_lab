## Findings

### CR-201-未修复-中-合法的长字段会越过 A4 右边界而被裁切
- **入口/函数**: `render_report_pdf()` 内部 `line()`
- **文件(行号)**: `backend/dga/laboratory/report_pdf.py:53-62`
- **输入场景**: 现场名称、样品备注或设备路径接近现有业务上限（现场 200 字符、备注 2000 字符；renderer 截到 180 字符）。
- **实际分支**: `_safe(value)` 返回最长 180 字符，`line()` 使用一次 `drawString(left + 38 mm, y, value)`。
- **预期行为**: 任何允许保存并进入定稿快照的文本都应在报告可打印宽度内换行，并在跨页时延续。
- **实际行为**: ReportLab 不自动换行，文本会越过 `right`，在 PDF 页面外被裁掉；现有 QA fixture 的短文本无法发现该问题。
- **直接证据**: `line()` 没有按 `pdfmetrics.stringWidth` 或可用宽度切分；`_safe` 的 180 字符上限远大于单行 A4 可用宽度。收样/检测输入允许长现场和备注。
- **影响**: 用户可见报告缺失合法数据 / PDF 验收不可靠
- **修复方向**: 在 renderer owner 内按字体宽度做中英文安全换行；每个 continuation line 都执行页底检查；增加长中文/ASCII fixture，并渲染到 PNG 或使用页面内容/页数断言验证未越界。
- **修复风险**: 低
- **严重程度**: 中
