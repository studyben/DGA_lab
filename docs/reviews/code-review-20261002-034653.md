## Findings

### AGG-1-已修复-[中]-Linked local credential password rotation could extend an OIDC absolute session

- **Disposition**: accepted; fixed; independently re-reviewed. No deferred finding.
- **入口/函数**: POST /api/auth/password -> IdentityService.change_password after explicit OIDC identity binding and employee login.
- **文件(行号)**: backend/dga/shared/auth/public.py:216–224; backend/dga/shared/auth/http.py:74–78; backend/dga/shared/auth/oidc.py:325. Original vulnerable behavior belongs to pre-fix c3a1211.
- **输入场景**: A supported legacy/recovery password-backed account is explicitly linked, verifies through OIDC at T, then changes its password at T+7h while local session_hours=24.
- **实际分支**: change_password discarded the resolved original session and called _new_session without expires_at. The default lifetime replaced the original OIDC deadline.
- **预期行为**: Password rotation revokes old tokens but does not constitute a new Okta login or extend the eight-hour absolute deadline.
- **实际行为**: Before fix, expiry became T+31h (T+15h under default8h); the HTTP cookie also received a complete new lifetime.
- **直接证据**: New public-interface linked-account regression and full HTTP regression both failed before the fix on changed expires_at. Existing tests had covered session reads, not password rotation for linked accounts.
- **影响**: Extends the accepted maximum existing-session window after provider-side removal; requires valid current local password and does not itself grant roles. Severity medium/P2.
- **建议改法和验证点**: Preserve original resolved expires_at while rotating token/CSRF and deleting prior sessions; derive cookie Max-Age from remaining lifetime. No additional provenance schema required. Tests verify T+7h rotation, unchanged T+8h deadline under24h local setting, revoked old token and refusal at original expiry; HTTP verifies approximately1h remaining cookie.
- **修复风险（低/中/高）**: 低至中; local password rotations now also retain their original deadline, documented as not a fresh login. A new explicit local login still authenticates independently.
- **严重程度（低/中/高/严重）**: 中.
- **Re-review evidence**: change_password now consumes existing['expires_at']; standard auth response computes nonnegative remaining seconds. Reviewer traced both and new public/HTTP assertions; full suite and key browsers pass after fix.

No further material defects found within covered paths. Prior slice findings (last-admin policy, UI stale input/save feedback, network-time expiry, immutable callback and proxy query redaction) have fixed/re-reviewed records in corresponding review artifacts.
