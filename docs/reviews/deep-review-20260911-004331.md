## Findings

### DR-301 — medium — product plan still prescribed the superseded versioned publication model

`PROJECT_PLAN.md` described a separate publish action, annual report number, immutable result/report revision history and supplementary reports. Those requirements conflict with the accepted Issue #7/#8 model and implemented public contract: an open sample permits editing, withdrawal reopens a finalized sample, overall finalization automatically queues one current report per barcode, and re-finalization replaces it without visible history. Leaving the stale model would cause later agents to reintroduce explicitly rejected scope.

Status: accepted and fixed in this pass. The result/report lifecycle and delivery checklist now record the already accepted withdrawal/re-finalization/current-report behavior and explicitly defer branding, signature and external delivery.
