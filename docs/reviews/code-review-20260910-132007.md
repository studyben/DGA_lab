- **输入场景**: Any migration, maintenance statement, fixture, or later code sets `testing_status='FINALIZED'` without setting finalizer metadata (the current baseline regression test does exactly this).

- **直接证据**: Constraint lines 26–30 omit `testing_status`; existing test line 738 updates only status and succeeds.
- **影响**: Inconsistent authoritative state, missing attribution, and later consumers potentially treating an unaudited row as report-ready.
