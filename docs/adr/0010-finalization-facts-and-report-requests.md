# 独立保存定稿事实，报告请求复制冻结证据

2026-10-29，#51已确认目标及接受计划115ba812承接批量导入父规格[#47](https://github.com/studyben/DGA_lab/issues/47) D10/D12。原已接受ADR-0009《导入检测资料与第三方原始报告分别管理》的权威原件仍保留在[G工作区](<G:/Sungrow Develop/DGA Lab/docs/adr/0009-imported-tests-and-source-reports.md>)，不复制其周边未提交文档。本决策只落实其必要兼容前置。

## 决策

实验室在整体定稿同一事务写入不可变、内部版本化事实：油样/token、采样时物理身份、全部活动检测与采用结果、方法配置和已确认警告。当前性仍由油样FINALIZED及当前token决定；撤回清除token，不修改历史事实。新事实schema2记录完整清单，旧schema1只保留原报告快照证实的采用结果，完整清单未知。

报告模块继续拥有排队/租约/生成token/对象及校验元数据。普通定稿仍自动排队，但报告只复制已保存事实，worker和重试不重建当前资产/方法/检测历史。现有schema1报告渲染器和旧READY文件字节保留。定稿、事实、普通请求、事件及审计共同提交或回滚。

0033追加至0032，不修改既有合并节点。迁移保留当前匹配非空token的原快照，包括损坏内容以便明确失败；不生成缺失token或未知来源/精度。合法0006→0007的NULL-token记录仍不构成分析候选，仅保留单样品诊断。完整旧PDF的字节读取与typed事实校验分离；没有权限/当前token的文件仍不可访问。

## 后果

- 事实禁止UPDATE/DELETE；存有事实时拒绝破坏性降级，使用向前恢复。用户无报告版本概念。
- 当前授权使用共享身份公开事务guard，锁顺序身份→配置（定稿）→样品→事实/报告→事件/审计；保留#18分析员定稿grant。
- 合法旧生产者fixture及真实PostgreSQL迁移证明兼容，不手改新JSON冒充旧事实。缺完整历史清单/来源时保持未知。
- S1先交付安全存储与普通报告兼容；受控公开NO_REQUEST、有效结果读取者切换及报告页解释由同一计划S2完成。S1不开放新HTTP跳过核对、不导入外部数据或DATE-only事实。
- 不新增任务框架、文件provider、跨模块写入或分析私有表依赖；不补造ASTM、正式阈值、历史安装或科学精度。
