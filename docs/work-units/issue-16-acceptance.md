# Issue16 本地验收

仅测试环境：http://127.0.0.1:18108/assets/analysis/rules 。账号 browser-admin，密码沿用隔离浏览器测试账号，不用于生产。未修改原18097验收数据。

1. 健康规则页查看规则说明；按关键词/状态筛选。
2. 使用已配置方法保存草稿，明确结果项、单位、生效时间、阈值及优先级。当前测试值没有科学含义。
3. 批准启用，填写原因。已启用内容不可编辑，复制生成新草稿；变更记录可追溯审批人、时间和原因。
4. 设备详情属性区查看自身/子设备汇总状态。异常标红，未知项显示原因，不能视作正常。
5. 展开评估来源，核对采样时间、条码、检测方法版本、单位、值、选中规则；有实验室权限时进入检测记录和条码报告。
6. 停用规则，再刷新设备。旧证据仍可由 health/{asset_id}/evaluations/{evaluation_id} 接口读取，但当前状态按当前规则重新计算。

口径：最新采样时间优先，不退回旧兼容/数值结果。同时间并列保留所有项；ND/LT/GT不作精确数值判断。方法不转换。多规则仅选最高优先级；同优先级范围/时段重叠不允许启用。父设备只聚合当前安装子设备，拆离后不再贡献原父状态。

时间：输入使用本机时区；未修改的已有精确时刻原样保留。新增夏令时重复小时采用浏览器默认首次时刻，界面明示；不存在本地时刻拒绝。有效截止时间不含该时刻。当前检查与证据形成时间分别显示。

尚不包含：正式阈值、ASTM兼容推断、报警处理工作流（后续Issue）、后台无人值守告警投递。保持当前Issue范围，未推送/合并。
