## State machine

- Reconciliation first validates retained recovery evidence by full source fingerprint/token against current finalized points (not current rule status: later rule retirement must not undo a legitimate retained recovery). If recovery evidence withdrawn/corrected, append RECOVERY_INVALIDATED and reopen unless a current eligible normal proves recovery. First acknowledgement retained.
- If an older recovery is invalidated while a later episode is already open, restore earliest unresolved episode and append consolidation events linking later episode via superseded_by; later timeline remains readable and is visibly marked “已并入原报警”, not “恢复正常”. Unique active key maintained transactionally. Historical observed episodes never physically merged/deleted.
- Latest grouping asset/type/analyte uses #16 rules. Abnormal latest evidence creates episode or appends changed observation; repeat exact same input no event/revision churn. Newer abnormal updates recovery baseline; same or older evidence cannot lower max abnormal sampled_at. Capture latest abnormal method/unit set; differing tied versions block later recovery unless all exact baseline method/unit agree.
- Open episode resolves only latest sampled_at strictly greater than baseline, every tied latest source NORMAL/EQ/configured, all exact baseline method/unit. Qualified/missing/rule-disabled/mismatch leaves unresolved with reason; rule-only reinterpretation and same-sample edit cannot resolve. Once resolved, same or older abnormal input must not reopen a new episode; later abnormal sample starts new episode. Initial sync only latest current inputs, not backfilling unobserved old events.
- Trigger evidence invalidation flags source_no_longer_finalized without deleting episode; do not silently fall back to old normal. Later eligible normal can still recover. Current health #16 remains unchanged, separate unresolved-alarm count/entry may remain red alongside normal/unassessed health with explanation.
- Persist original trigger, latest abnormal, recovery, source validity and policy interpretation details; JSON precision uses existing encode/Decimal string convention. Current location joined from owner read each query; immutable trigger sampling snapshot separately labeled. Missing/replaced parent never clears physical alarm.
